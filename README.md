# Empreinte Locale - Marketplace des Artisans Ivoiriens

**Empreinte Locale** est une Progressive Web App (PWA) premium dédiée à la valorisation du savoir-faire des artisans de Côte d'Ivoire. Cette plateforme permet de découvrir plus de 400 articles authentiques, d'écouter leurs histoires et de soutenir directement les créateurs locaux.

## 🚀 Fonctionnalités

- **Catalogue Immersif** : 400+ articles répartis en 6 catégories (Mode, Bijoux, Déco, Cosmétiques, Agriculture, Transformés).
- **Expérience "Écouter & Voir"** : Lecture vocale de l'histoire de chaque produit avec animation sonore.
- **Profils Artisans** : Découvrez les 30 artisans derrière les créations (biographies, photos, contacts).
- **Panier & Commandes** : Flux d'achat complet avec gestion de l'historique des commandes.
- **Paiements Mobiles** : Intégration visuelle des logos Orange Money, Wave et MTN MoMo.
- **Administration Locale** : Gestion CRUD complète des articles et artisans via le stockage local (localStorage).

## 🛠️ Installation Locale

1. Clonez ce dépôt.
2. Ouvrez le fichier `index.html` dans votre navigateur.
3. Pour une expérience optimale, utilisez une extension de serveur local (ex: Live Server sur VS Code).

## 🌍 Déploiement

Ce projet est conçu pour être hébergé sur des services statiques comme :
- **GitHub Pages**
- **Netlify**
- **Vercel**

## 📱 PWA (Progressive Web App)

L'application est optimisée pour mobile et peut être installée sur votre écran d'accueil comme une application native.
